# AI 复制粘贴

**我用 AI 写了一个软件，塞了 80 个大模型，轻松实现 Ctrl+C 和 Ctrl+V复制粘贴功能**

AI 写代码，AI 写文档，AI 写宣传稿。软件再调用 AI，把原文还给你。

从研发到交付，构建完整的 AI 原生文本流转生态闭环。

按下 Ctrl+C，复制文本，然后把文本发给大模型。

再按 Ctrl+V，让大模型把刚才的文本原封不动地输出，再粘贴出来 实现高效的工作日常操作。

不总结，不润色，不翻译。一个字都别改。谢谢。

这个功能十分简单，十分实用

这就是 **80 个大模型的威力**。

## 高级功能

- **AI 复制**：把本来已经复制好的文本，再发给大模型。
- **AI 粘贴**：让大模型原封不动地返回文本，然后粘贴。
- **LLM大模型**：计划接入 80 个模型，让它们都有机会承担复制粘贴的重任。
- **支持 API 接入**：计划支持自定义 API 地址、API Key 和模型名称。复制粘贴，也得有自己的基础设施。
- 支持月付/年付会员, 80$/月, 1000$/年 会员支持解锁尊享隐藏功能: buy me a coffee
